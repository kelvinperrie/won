# WON: War On Nature

https://won-zeta.vercel.app/

WON is an idle clicker game that runs in the browser. Animals wander onto the screen and the player hunts them, moving with WASD and shooting with the mouse. Each kill earns points, which can be spent on upgrades, on extra units that hunt automatically, and on lures that attract more animals. Everything in the game is drawn as text. Progress is saved in the browser's local storage. To play, open `index.html` in a modern browser.

## Tests

The game logic has tests that run in Node.js (version 18 or later) with no other dependencies. To run them, use `node --test` from the project folder.
